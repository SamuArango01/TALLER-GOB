# Presentación Taller Rastro - Monastery.com.co

Presentación web interactiva para el taller de **Ciberseguridad y Gobernanza de Datos (ST1630)**.

## 🚀 Despliegue en Vercel

### Opción A: Desde el Navegador / Dashboard de Vercel (Recomendado)
1. Sube este proyecto o la carpeta `presentacion-rastro` a un repositorio de **GitHub**.
2. Entra a [vercel.com/new](https://vercel.com/new).
3. Importa el repositorio de GitHub.
4. Haz clic en **Deploy** (Vercel detectará el archivo `index.html` automáticamente como sitio estático sin necesidad de comandos de build).

### Opción B: Usando Vercel CLI desde la Terminal
```bash
cd presentacion-rastro
npx vercel
```

## 💻 Visualizar Localmente
Para abrir la presentación de inmediato en tu navegador sin instalar nada, simplemente abre el archivo `index.html` haciendo doble clic sobre él o ejecutando:

* **Windows:** `start index.html`
* **macOS:** `open index.html`
* **Linux:** `xdg-open index.html`

## ⌨️ Controles de la Presentación
* **Flecha Derecha / Barra Espaciadora:** Avanzar a la siguiente diapositiva.
* **Flecha Izquierda:** Retroceder a la diapositiva anterior.
* **Puntos de Navegación:** Haz clic en los puntos inferiores para saltar directamente a cualquier diapositiva.
* **Botón de Pantalla Completa:** Icono en la barra superior derecha.
